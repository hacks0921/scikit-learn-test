# scikit-learn-test

## 📝 프로젝트 소개
사이킷런(Scikit-Learn) 머신러닝 라이브러리의 다양한 모델 실습과 당뇨병 진행률 예측 회귀분석, 서울 공공 자전거(따릉이) 수요 예측 회귀분석 등을 포함한 전통적인 머신러닝 실습실입니다.

## 🛠 주요 사용 기술
- Python 3
- Scikit-Learn
- pandas / numpy (데이터 전처리)
- matplotlib / seaborn (학습 결과 그래프 시각화)

## 📂 주요 파일 구성
- `210206_bike-sharing-demand.py`: 공공 자전거 수요 데이터를 로드하여 기상 정보 및 시간 요소를 변수화하고 수요 강도를 예측하는 모델
- `210207_diabetes_5(randomforest).py`: 랜덤포레스트 앙상블 학습 알고리즘을 이용한 고차원 피처 훈련 예제
- `210207_diabetes_6(randomserch).py`: 모델의 하이퍼파라미터 튜닝 최적화를 자동화하는 Random Search CV 실습 예제
- `210208_AutoScikitLearn.py`: AutoML 기반의 자동 모델 탐색 프로세스 실습 기록
